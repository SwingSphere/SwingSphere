# Language Explorer Recovery Exhibit

This is an original, self-contained explanatory preview of what is present in
the local `analysis_output` archive. It does not execute the recovered Google
JavaScript or CSS and is not a clone of the original site.

## Open directly

Double-click `index.html` or open it in a browser.

## Serve locally

From `G:\sites\GoogleGlobe`:

```powershell
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/language-explorer-recovery-preview/
```

The exhibit is a single HTML file with embedded CSS and JavaScript. It has no
network or build dependencies.
