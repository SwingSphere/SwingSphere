03 · gaps

What the scrape did not capture

These gaps prevent a faithful local run. Reconstructing them would require new implementation, properly sourced data, and explicit licensing review—not guesswork around the archived bundles.

MISSING / 01

Imported code chunks

At least eight referenced modules are absent, including shared Three.js, settings, routing, and lazy-loaded view chunks.

MISSING / 02

Language datasets

The six named language, country, region, script, endangerment, and speaker-count datasets were referenced but not saved.

MISSING / 03

Country geometry

The configured country mesh/JSON payload needed to render and raycast the actual globe is not present in the archive.

MISSING / 04

Audio and video

Many language recordings, interface sounds, and intro media URLs were discovered, but the media itself was not recovered.

MISSING / 05

Page and build graph

The HTML “snapshot” is only a 64-byte fetch representation. There is no complete document, manifest, source map set, or lockfile.

MISSING / 06

Content services

No backend, editorial source, update workflow, analytics configuration, or authoritative licensing context was captured.
